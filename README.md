# lauryncele.dev

Personal site for **Lauryn N. Cele**, Senior Frontend Developer.

## Stack

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- Framer Motion

## Scripts

```bash
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
```

## Deploy

Vercel (or any static host). Build command `npm run build`, output `dist`.
